# Библиотека

Десктопное приложение для учёта книг, читателей и выдач в библиотеке.

Проект разработан на Python с использованием Tkinter для графического
интерфейса и SQLite для хранения данных.

## Возможности

Приложение позволяет:

- добавлять, редактировать и удалять книги;
- хранить информацию о количестве экземпляров;
- добавлять, редактировать и удалять читателей;
- выдавать книги читателям;
- учитывать количество доступных экземпляров;
- возвращать выданные книги;
- сохранять информацию между запусками программы.

## Технологии

- Python
- Tkinter
- SQLite
- Git
- GitHub
